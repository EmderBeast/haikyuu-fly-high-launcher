Haikyuu Fly High - Private Server Launcher
==========================================

Voraussetzungen
---------------
- Windows 10/11
- LDPlayer 9 oder LDPlayer 14 (https://www.ldplayer.net) mit installiertem
  Haikyuu Fly High (com.garena.game.haikyu)
- Root im LDPlayer (der Launcher fragt nach und schaltet es selbst ein)

Start
-----
1. Den Ordner "HFH-FlyHigh" irgendwohin entpacken (z. B. Desktop oder Dokumente,
   NICHT nach "C:\Programme").
2. HFH-Launcher.exe doppelklicken. Falls Windows warnt ("Der Computer wurde
   durch Windows geschützt"): "Weitere Informationen" -> "Trotzdem ausführen".
   Die Windows-Firewall-Frage mit "Zulassen" beantworten.
3. Der Launcher startet den Server, den Proxy, LDPlayer und das Spiel.
   Im Spiel ganz normal mit dem Garena-Konto anmelden.

Bedienung
---------
- "Private Server"     Spiel verbindet sich mit dem eigenen Server (Standard).
- "Garena (offiziell)" Spiel verbindet sich wieder mit Garena (falls deren
                       Server mal online sind).
  Nach dem Umschalten wird das Spiel automatisch neu gestartet.
- "Spiel neu starten"  beendet das Spiel im Emulator und startet es neu.
- "Emulator"           Auswahl der LDPlayer-Instanz, falls es mehrere gibt;
                       "Verbinden" richtet alles neu ein.
- "Server"             leer = eigener Server auf diesem PC (Standard).
                       Adresse eines gemeinsamen Online-Servers eintragen
                       (z. B. "hfh.example.org" oder "1.2.3.4:10104") und
                       "Übernehmen" -> du spielst mit den anderen auf diesem
                       Server (Arena gegen ihre Teams). Das Spiel startet neu.
                       Admin Mode gibt es dort nicht.
- "Backup"             sichert alle Spielstände nach "backups" (passiert auch bei
                       jedem Start automatisch; die letzten 20 bleiben).
- "Wiederherstellen"   spielt ein Backup wieder ein (der aktuelle Stand wird vorher
                       gesichert, der Server kurz neu gestartet).
- "LDPlayer laden"     erscheint, wenn kein LDPlayer installiert ist: öffnet die
                       Download-Seite.
- "Update verfügbar"   erscheint, wenn es auf GitHub eine neue Version gibt: lädt sie und
                       installiert sie selbst (Launcher startet neu). Spielstände und
                       Backups bleiben erhalten.
- Fenster schließen    beendet Server und Proxy.

Admin Mode (nur in der Admin-Version "HFH-FlyHigh-Admin")
-----------------------------------------------------------
1. Im Spiel: Einstellungen -> "Gift Code" -> Admin-Passwort eingeben -> "Redeem".
2. Im Launcher erscheint der Knopf "Admin Mode". Dort kann man Level, Gold,
   Diamanten, alle Charaktere, Max-Karten, Gegenstände und Potentials einstellen.
3. "Übernehmen & Spiel neu starten" -> im Spiel auf START tippen, fertig.

Ohne Server-Adresse hat jeder Spieler seinen eigenen Server auf dem eigenen PC
(auf einem Online-Server liegen die Spielstände dort); die Spielstände
liegen im Ordner server\accounts.

Probleme
--------
- "kein Root": die Frage des Launchers mit "Ja" beantworten – er startet LDPlayer
  mit Root neu. (Von Hand: LDPlayer-Einstellungen -> Sonstiges -> Root-Berechtigung: An.)
- "nicht installiert": der Launcher fragt nach der Spieldatei (.apk, .xapk, .apks
  oder .apkm) und installiert sie selbst.
- Das Log unten im Fenster zeigt, woran es hängt. Es steht auch in launcher.log im
  Launcher-Ordner – die Datei bei Problemen einfach mitschicken.
